# 模型压缩列表（CompressView）「有数据时」肉眼复核清单

> 页面：`/compress` → `maas-web/src/views/compress/CompressView.vue`
> 关联规范：`docs/plan/ui/list-ui-ux-conventions.md`
> 复现：创建至少 2 条压缩任务，使其处于不同状态（`running`/`succeeded`/`failed`），并至少 1 条 `running` 进度>0。

## A. 数据与基础
- [ ] 列表出现行；分页条显示正确总数/页码（有数据才显示 `PaginationBar`）。
- [ ] 加载中显示骨架；接口失败显示错误态 + 重试；无数据显示空态（含创建入口）。
- [ ] 切换「方法/状态」筛选后**行数变化**，且 Network 请求含 `method=`/`status=`（端到端）。
- [ ] 「重置」清空筛选并回到第 1 页。
- [ ] 搜索关键字后请求含 `keyword=` 且结果匹配。

## B. 列与对齐（本次改动重点）
| 列 | 预期 |
|---|---|
| 名称 | 左对齐、可点击跳详情；13px |
| 方法 | **居中**；显示方法本地化名 |
| 量化精度 | **居中** |
| 状态 | **居中** + `StatusTag`（失败=红、进行中=蓝/琥珀、成功=绿） |
| 源制品 / 校准集 / 产物 | 有值显示，无值 `—` |
| 进度 | **居中**；进度条高 **4px**；`running` 有百分比推进 |
| 创建时间 | **居中**、12px、次级色、格式 **`YYYY-MM-DD HH:MM:SS`**（无 `T`、无毫秒、无时区后缀） |
| 操作 | **右对齐**、末尾留白小；按钮文字 12px、图标 13px |

## C. 操作语义化
- [ ] `详情`：中性色 + `PhEye` 图标。
- [ ] `取消`（仅可取消时出现）：**危险色** + `PhX` 图标；点击弹二次确认，确认后状态变更并刷新。
- [ ] 无 `⋯` 冗余下拉。
- [ ] 危险与中性操作间有分隔符（若有取消）。

## D. 工具条
- [ ] 顺序：`搜索 ‖ 分隔符 ‖ 方法筛选 ‖ 状态筛选 ‖ 重置(图标)`。
- [ ] 分隔符为 1px 竖线；重置带 `PhArrowsClockwise` 图标。

## E. 视觉/一致性
- [ ] 全表内容 13px；表头与内容对齐一致。
- [ ] 浅色/深色均正常；窄屏可横向滚动、不压缩截断。
- [ ] 数字（进度/百分比）使用等宽数字（tabular-nums）。
- [ ] 18 语种切换后表头/按钮/状态文案本地化（无缺失、无英文占位）。

## F. 交互细节
- [ ] 行内点击「详情」不误触其它按钮（`@click.stop` 生效）。
- [ ] `running` 任务进度随 SSE/轮询更新；终态停止高频刷新。
- [ ] 键盘可达（`focus-visible` 聚焦环）、`aria` 无报错。

## G. 与规范文档一致
- [ ] 对照 `docs/plan/ui/list-ui-ux-conventions.md`「统一实现约定」逐项通过（时间精简 / 进度细化 / 操作列 / 工具条 / 语义色）。
- [ ] 截图留存（浅/深各一张）用于回归。

---

## 复用到其它列表页（把本清单泛化）
- **B 列与对齐**：替换为“目标页各列 + 预期对齐/宽度/字号”；通用项——状态/时间/进度居中、数值右对齐、时间用 `YYYY-MM-DD HH:MM:SS`。
- **C 操作语义化**：替换为“目标页动作集”；通用项——`详情`=中性 `PhEye`、主操作=主色、危险=红 `PhTrash/PhX`、无冗余下拉。
- **D 工具条**：`搜索 ‖ 分隔符 ‖ 筛选 ‖ 重置(图标)`。
- **A/E/F/G**：与页面无关，直接复用（筛选端到端、深浅色/响应式、tabular-nums、18 语种、聚焦环、规范对照）。

> 命名建议：`docs/plan/ui/reviews/<page>-list-review.md`（如 `training-list-review.md`、`inference-list-review.md`）。
