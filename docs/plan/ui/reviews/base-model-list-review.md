# 基座模型列表「有数据时」肉眼复核清单

> 页面：``/base-models` → `maas-web/src/views/base-models/BaseModelsView.vue``
> 关联规范：`docs/plan/ui/list-ui-ux-conventions.md`
> 复现：≥2 个基座模型，覆盖 different 来源(HF/ModelScope)与状态；至少 1 个有最近拉取记录。
> 通用项：A/E/F/G 同 `compress-list-review.md`（见文末节摘要）。

## B. 列与对齐（本次改动重点）
| 列 | 预期 |
|---|---|
| 名称 | 左对齐；副行「系列 · 参数档位/提供方」；13px；可点击跳详情 |
| 来源 | 仅**短徽标**（HF/MS）；居中 |
| 权重格式 | 左/常规 |
| 大小 | **右对齐** tabular-nums |
| 状态 | **居中** + `StatusTag`(base-model) |
| 最近拉取 | **居中**；进度条 **3px、等长、居中**；文字与条左端对齐、单行不折行+气泡；**成功状态图标已去除**（状态列已有） |
| 更新时间 | **居中**、12px、次级色、`YYYY-MM-DD HH:MM:SS`（无 T/毫秒/时区） |
| 操作 | **右对齐**、末尾留白小；文字 12px、图标 13px |

- [ ] 顶部**概览条/健康栏**：「基模」计数在「变体」计数**之前**；结论文字带语义色。
- [ ] 列表页健康内联在搜索行（重置右侧）+ 显隐开关（默认显示）。

## C. 操作语义化
- [ ] `详情`(中性 `PhEye`) ‖ `拉取/重新拉取/重试`(主色) ｜ `暂停/恢复`(中性 `PhPause/PhPlay`) ｜ `开始/重新分析`(中性 `PhMagnifyingGlass`) ‖ `取消/删除`(危险 `PhX/PhTrash`)。
- [ ] 无 `⋯` 冗余下拉；危险项与中性项间有分隔符。

## D. 工具条
- [ ] `搜索 ‖ 分隔符 ‖ 来源筛选 ‖ 状态筛选 ‖ 系列筛选 ‖ 重置(图标)`。
- [ ] **来源筛选端到端**：选择后请求含 `source=`，行数变化。

## A. 数据与基础
- [ ] 列表渲染行；分页正确；加载骨架 / 错误态+重试 / 空态（含入口）。
- [ ] 筛选/搜索后端生效：操作后行数变化，Network 请求含对应查询参数（端到端）。
- [ ] 「重置」清空筛选并回到第 1 页。

## E. 视觉/一致性
- [ ] 全表内容 13px；表头与内容对齐一致。
- [ ] 浅色/深色正常；窄屏可横向滚动、不压缩截断。
- [ ] 数值列使用等宽数字（tabular-nums）。
- [ ] 18 语种切换后表头/按钮/状态本地化（无缺失/英文占位）。

## F. 交互细节
- [ ] 行内动作不误触其它按钮（`@click.stop`）。
- [ ] 运行中任务随 SSE/轮询更新；终态停止高频刷新。
- [ ] `focus-visible` 聚焦环；无 `pageerror`。

## G. 与规范文档一致
- [ ] 对照 `docs/plan/ui/list-ui-ux-conventions.md`「统一实现约定」逐项通过。

## 复用到其它列表页
- B（列与对齐）：按目标页替换列与预期；通用——状态/时间/进度居中、数值右对齐、时间 `YYYY-MM-DD HH:MM:SS`。
- C（操作语义化）：`详情`=中性 `PhEye`、主操作=主色、危险=红 `PhTrash/PhX`、无冗余下拉。
