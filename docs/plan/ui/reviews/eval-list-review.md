# 模型评测列表（EvalView）「有数据时」肉眼复核清单

> 页面：`/eval` → `maas-web/src/views/eval/EvalView.vue`（两个 Tab：评测任务 / 金标集）
> 关联规范：`docs/plan/ui/list-ui-ux-conventions.md`
> 复现：至少 2 条评测任务（覆盖 `running`/`succeeded`/`failed`，≥1 条有分数与门禁结果）+ 至少 2 条金标集（不同任务类型/状态）。

## A. 数据与基础
- [ ] Tab 切换正确（评测任务 / 金标集），各自独立加载/分页。
- [ ] 加载中骨架；失败错误态 + 重试；空态含创建/登记入口。
- [ ] 评测任务：搜索关键字 + 状态筛选后**行数变化**，请求含 `keyword=`/`status=`（端到端）。
- [ ] 金标集：搜索关键字后请求含 `keyword=` 且结果匹配。
- [ ] 「重置」清空筛选并回到第 1 页（两 Tab 各有）。

## B1. 评测任务 — 列与对齐（本次改动重点）
| 列 | 预期 |
|---|---|
| 任务名称 | 左对齐、可点击跳详情；副行显示评测类型；13px |
| 制品 / 推理实例 / 金标集 | 显示名称（解析自 ID），无值 `—` |
| 分数 | **右对齐**；百分比（如 `87.5%`） |
| 门禁 | **居中**；通过=绿、未通过=红、无 `—` |
| 状态 | **居中** + `StatusTag` |
| 创建时间 | **居中**、12px、次级色、格式 **`YYYY-MM-DD HH:MM:SS`**（无 `T`/毫秒/时区） |
| 操作 | **右对齐**；`详情`=中性 `PhEye`，文字 12px、图标 13px |
- [ ] **「类型」列已移除**（评测类型并入名称副行，不再单独成列）。

## B2. 金标集 — 列与对齐
| 列 | 预期 |
|---|---|
| 编码 / 名称 | 左对齐；13px |
| 任务类型 | **居中** |
| 版本 / 样本数 | 右对齐 |
| 存储地址 | 等宽（mono），过长省略/气泡 |
| 状态 | **居中** + `StatusTag(type=eval-set)` |
| 创建时间 | **居中**、12px、次级色、`YYYY-MM-DD HH:MM:SS` |
- [ ] 金标集表**无操作列**（按当前设计）。

## C. 操作语义化
- [ ] `详情`：中性色 + `PhEye`，右对齐、末尾留白小。
- [ ] 无 `⋯` 冗余下拉。

## D. 工具条
- [ ] 评测任务：`搜索 ‖ 分隔符 ‖ 状态筛选 ‖ 重置(图标)`。
- [ ] 金标集：`搜索 ‖ 重置(图标)`。
- [ ] 分隔符 1px 竖线；重置带 `PhArrowsClockwise` 图标。

## E. 视觉/一致性
- [ ] 全表内容 13px；表头与内容对齐一致。
- [ ] 浅色/深色正常；窄屏横向滚动、不压缩截断。
- [ ] 分数/版本/样本数 tabular-nums。
- [ ] 18 语种切换后表头/按钮/状态本地化（无缺失、英文占位）。

## F. 交互细节
- [ ] 行内「详情」不误触其它控件（`@click.stop`）。
- [ ] `running` 任务进度/状态随 SSE/轮询更新；终态停止高频刷新。
- [ ] `focus-visible` 聚焦环、`aria` 无报错。

## G. 与规范文档一致
- [ ] 对照 `docs/plan/ui/list-ui-ux-conventions.md`「统一实现约定」逐项通过。
- [ ] 截图留存（评测任务/金标集 × 浅/深）。
