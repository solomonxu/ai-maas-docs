<a id="glossary"></a>
## 一、术语表

| 术语 | 含义 |
|---|---|
| 语音转写（ASR） | 把录音转成文字 |
| 语音合成（TTS） | 把文字转成语音 |
| 音色 | 合成语音时使用的声音身份 |
| 执行器 | 实际运行转写或合成任务的进程 |
| 租约 | 执行器占用资源的临时凭证 |
| 对象存储 | 保存音频和合成结果的存储服务 |
| 保留期 | 结果在系统中保留的时间 |
| 字错率（CER） | 识别文本与标准文本之间的字级差异 |
| 词错率（WER） | 按词计算的识别差异，适合有空格的语言 |
| 可商用 | 代码、权重、音色均满足商业使用要求 |

<a id="language-list"></a>
## 三、语言清单

说明：

- 语言名称以 Unicode CLDR 为参考；
- 人口为公开资料量级估算，混合第一语言和第二语言；
- 使用区间而不是精确人口，避免统计口径误导；
- “主要分布”只列代表性地区，不构成政治边界判断；
- TTS/ASR 状态对应本文时间截面。

**状态说明：**

- 可用：通过质量门禁；
- 评测中：链路可用，业务质量仍在评估；
- 试用：保留入口，质量样本不足；
- 非商用：技术可用，商业使用前需要解决授权。

> 使用人口为量级估算，混合第一语言和第二语言，统计口径不同。

## 四、说明

- 人口数据来自 Unicode CLDR、Ethnologue 和公开统计资料的量级估算，统计年份和口径不同；
- 第一语言和第二语言混合计算，适合做覆盖参考，不支持精确人口排名；
- 语言状态会随真实样本和许可证变化，以当前服务目录为准；
- 非商用音色和语言在商业项目中使用前，需要单独解决授权。
