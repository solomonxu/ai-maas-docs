# 项目概述（Overview）

[简体中文](./overview.md) | [English](./overview.en.md)

## 一句话

AI MaaS 是一个**基座无关**、**私有化部署**的垂直行业大模型**微调与推理**平台（M0 开发中）。

## 定位与差异化

| 维度 | 说明 |
|---|---|
| 基座无关 | 统一模型描述 + 推理后端适配，替换 Qwen/Llama/DeepSeek 等**只需改配置**，不改业务代码 |
| 私有化 | 数据不出域；支持内网/离线部署，面向前述合规敏感行业 |
| 端到端 | 拉取 → 扫描 → 微调 → 评测 → 量化/压缩 → 推理 |
| 工程化 | COLA DDD 微服务 + WS 统一控制面 + 前后端分离 |

## 目标用户

- 需要**私有化**大模型能力的金融/法律/政务等组织；
- 希望**快速试用与替换**多种开源基座的团队；
- 关注**合规、可观测、可治理**的 AI 平台建设者。

## 核心概念

- **基座模型（Base Model）**：可微调/推理的原始权重（如 `Qwen/Qwen2.5-0.5B`）。
- **变体（Variant）**：最小可部署单位（单文件或一组文件），带格式/精度/量化属性；分 `model`/`component` 角色。
- **运行时（Runtime）**：Python 侧执行体（拉取/训练/推理/扫描等），经 WebSocket 受控。
- **制品（Artifact）**：训练/压缩产物（LoRA、量化权重等），可登记与晋级。

## 非目标（当前阶段）

- 不追求全量模型训练（聚焦微调/LoRA 与推理）；
- 不内置大模型权重（由用户自行拉取/导入并遵守其许可）；
- M0 不做大规模数据清洗/索引与多客户治理（M1/M2 补齐）。
