# 项目概述（Overview）

[简体中文](./overview.md) | [English](./overview.en.md)

## 一句话

OpenMaas 是面向私有化部署的模型训推与推理平台，提供基座模型、数据集、训练、制品、推理、评测、压缩、资源治理和流水线能力。

## 定位

| 维度 | 说明 |
|---|---|
| Self-hosted | 数据与模型留在自有环境，适合内网、离线和合规敏感场景 |
| 基座无关 | 统一模型描述与推理后端适配，替换基座不改业务代码 |
| 端到端 | 拉取 → 数据 → 训练 → 制品 → 推理 → 评测 → 压缩 |
| 运行语义 | 预检快照、阶段状态机、数据库租约、恢复、成本与审计 |
| 工程化 | Java 微服务 + Python 运行时 + Vue 3 前端；COLA DDD 分层 |

## 目标用户

- 建设私有化 AI 平台的架构师和平台研发；
- 负责训练、推理、评测链路的 MLOps 团队；
- 关注资源治理、成本归集和合规审计的组织；
- 希望快速试用和替换多种开源基座的团队。

## 核心概念

- **基座模型（Base Model）**：可微调/推理的原始模型权重。
- **变体（Variant）**：最小可部署单位，带格式、精度和量化属性。
- **运行时（Runtime）**：Python 执行体，经 WebSocket 控制面接受任务。
- **模型制品（Artifact）**：训练或压缩产物，可注册、晋级和发布。
- **流水线运行（Pipeline Run）**：跨服务的训推长事务，包含阶段、预检、事件和成本。

## 能力边界

当前覆盖：

```text
基座管理 / 数据集 / 训练 / 制品 / 推理 / 评测 / 压缩 / 流水线 / 资源治理
```

不作为目标：

- 从零实现基础大模型训练框架；
- 自研推理引擎；
- 替代专业数据标注工具；
- 首版提供任意自由 DAG 编排；
- 首版提供完整财务结算系统。

## 项目状态

OpenMaas 处于开源收尾阶段，代码仓库和文档站即将开放。当前版本为 pre-1.0，接口和能力仍可能调整。
